# Security Policy

## Supported Versions

Modeless Design System is currently pre-1.0. Security fixes will target the latest published or repository-supported release line.

## Reporting A Vulnerability

Please do not open a public issue for a security vulnerability.

Report security concerns through GitHub's private vulnerability reporting for this repository when available. If that is unavailable, contact the repository maintainers through the organization profile.

Include:

- Affected package version or commit
- Reproduction steps or proof of concept
- Potential impact
- Any known mitigations

We will acknowledge valid reports as quickly as practical and coordinate a fix before public disclosure.
